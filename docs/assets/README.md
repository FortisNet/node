# Documentation images

This directory holds the images that the repository's `README.md` displays. Anyone who updates the FortisNet branding needs it.

- `fortisnet-logo.svg`: the FortisNet emblem and wordmark with dark lettering, for light backgrounds.
- `fortisnet-logo-light.svg`: the same with light lettering, for dark backgrounds.

Both files are self-contained SVG and are unmodified copies of the FortisNet brand lockups. Replace both together when the brand changes.

The images that the node itself serves are in [`assets/`](../../assets) at the top of the repository ([node-home.md](../node-home.md)).
